# Jetour: кабинет реферальной программы

Дизайн-концепт одной страницы, собранный в статичный прототип: HTML, CSS и JS, без сборки.
Анимации на GSAP и Lenis (файлы лежат в `assets/vendor`), шрифты Russo One и Manrope локальные.

Открыть: `index.html` в браузере или страница на GitHub Pages.
Рассчитан на десктоп от 1440 px. Мобильной версии нет.
